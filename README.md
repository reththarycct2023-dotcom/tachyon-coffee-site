# Tachyon — Buy Me a Coffee Website

A responsive, static one-page support website built around Tachyon's green-and-black channel branding. It includes the supplied logo and KHQR image as local assets.

## Preview locally

Open `index.html` in your browser. No build step, server, or third-party JavaScript dependency is needed.

## Publish online

### Netlify (quick option)
1. Sign in to Netlify and choose **Add new site** / **Deploy manually**.
2. Drag the whole `tachyon-coffee-site` folder (or the ZIP contents) into the deploy area.
3. Netlify will provide a public URL.

### GitHub Pages
1. Create a repository and upload the contents of this folder.
2. In the repository, open **Settings → Pages**.
3. Choose to deploy from the main branch and the root folder, then save.

## Customizing the copy

Edit `index.html`. The current channel description is deliberately broad because the public channel page could not be inspected through search. Replace the paragraph under **“Because ideas don’t edit themselves.”** with your exact niche/topics whenever you want.

## Payment safety

The supplied KHQR image is included unchanged at `assets/khqr-payment.png`. Before publishing, scan it yourself and confirm the recipient/payment details are correct. Do not crop, stretch, or replace the QR artwork with a re-created code.
